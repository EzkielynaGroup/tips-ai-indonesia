# Cara berkontribusi

Terima kasih sudah mau menambah tips! Pull request dari siapa pun sangat diterima.

## Yang kami cari

- Tips yang **sudah kamu coba sendiri** dan berguna untuk orang lain.
- Jebakan yang membuat tagihan membengkak, bot error, atau key bocor, beserta cara menghindarinya.
- Perbaikan salah ketik, link mati, atau informasi yang sudah usang.

## Aturan isi

1. **Bahasa Indonesia** yang jelas dan santai. Istilah teknis (token, base URL, prompt) boleh tetap dalam bahasa Inggris.
2. **Netral penyedia.** Tips harus bekerja di penyedia mana pun yang kompatibel. Boleh menyebut nama produk sebagai contoh, tapi bukan iklan. Link afiliasi dan promosi tidak diterima.
3. **Jujur dan bisa dicek.** Angka harga atau benchmark wajib menyebut sumber dan tanggal. Hindari klaim mutlak seperti "paling murah" atau "selalu".
4. **Jangan pernah menulis API key asli.** Pakai placeholder `sk-...`.
5. **Singkat.** Satu tips idealnya 1 sampai 5 kalimat. Kalau butuh lebih panjang, pertimbangkan bagian baru.

## Langkah

1. Fork repo ini, lalu buat branch: `git checkout -b tips-hemat-n8n`.
2. Tambahkan tips di file yang sesuai di folder [`tips/`](tips). Bagian baru? Buat file baru dengan nomor berikutnya dan tambahkan ke daftar isi di [README.md](README.md).
3. Cek link yang kamu tambahkan masih bisa dibuka.
4. Buka pull request dan jelaskan singkat: tips apa, dan dari pengalaman apa.

Punya ide tapi belum sempat menulis? Buka **issue** saja, kami bantu rapikan.

## Lisensi kontribusi

Dengan mengirim pull request, kamu setuju kontribusimu dirilis di bawah [CC BY 4.0](LICENSE), sama seperti isi repo lainnya.
